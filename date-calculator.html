Frequently Asked Questions

Does this calculator include the start date?
For "days between," we count from the start date to the end date. The exact count depends on whether you include both dates.
How does it handle leap years?
This calculator automatically accounts for leap years (every 4 years, except centuries unless divisible by 400).
